# 🤖 ML-LAB

Welcome to **ML-LAB**! This repository contains Machine Learning laboratory programs, experiments, and notebooks implemented using **Python**. It is designed for students to learn and practice fundamental Machine Learning concepts through hands-on coding.

---

## 📌 About

This repository includes Machine Learning lab experiments covering data preprocessing, supervised learning, unsupervised learning, and model evaluation. Each experiment is implemented with clear code to help understand the underlying concepts.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/kishoribaskaran-jpg/ML-LAB.git
```

2. Open the project folder.

3. Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn
```

4. Open the Jupyter Notebook:

```bash
jupyter notebook
```

5. Run the notebook or Python file.
